# DREAMS: premium apartment and room booking website

Open `index.html` in a browser (or serve the folder with any static host).

- `index.html`: page structure
- `css/style.css`: all styling (light and dark themes)
- `js/main.js`: scroll-controlled video, listings, availability search, booking and sign-in windows
- `assets/video/hero.mp4`: your walkthrough, re-encoded without audio and with dense keyframes for smooth scrubbing
- `assets/images/`: listing photos (optimised) and four stills taken from the video
- `assets/originals/`: your untouched uploads

Edit the listings at the top of `js/main.js` (the `L` array). Bookings, sign-in and the contact form are front-end only; connect a backend to store them.
